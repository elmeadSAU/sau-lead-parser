# Email Lead Parser

This Python project parses `.eml` files exported from Outlook (notification emails generated by WordPress / Gravity Forms) and extracts lead metadata into a structured CSV file.

## Extracted Fields
- Student Name
- Email Address
- Cell Phone
- Receive Texts (Yes/No)
- Birthdate
- Prospective Student Type
- Program of Interest
- Lead Source
- Parent Page URL
- Gravity Forms Entry ID (`id`)
- Gravity Forms Lead ID (`lid`)
- Submission / Email Date

## Setup Instructions for GA

1. Clone the repository:
   git clone <repository-url>
   cd email_parser

2. Set up a Python virtual environment:
   python3 -m venv venv
   source venv/bin/activate

3. Install dependencies:
   pip install -r requirements.txt

4. Run the parser:
   Drop new .eml files into the project root directory.
   Run: python3 parse_emails.py
   The script will export/overwrite parsed_leads.csv.

## Notes
- .eml files and parsed_leads.csv are ignored by Git (.gitignore) to prevent uploading student PII.
